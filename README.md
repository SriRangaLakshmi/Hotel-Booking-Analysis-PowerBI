# Hotel-Booking-Analysis-PowerBI

Developed an interactive Hotel Booking Analytics Dashboard using Microsoft Power BI to analyze hotel booking patterns, customer behavior, cancellations, waiting lists, booking charges, and special requests. The dashboard provides visual insights through charts, slicers, tables, and KPI cards, enabling users to explore booking trends across different hotels, countries, meals, reservation types, and arrival dates.

Key Features
📊 Interactive Hotel Booking Dashboard
🏨 Analysis of City Hotel and Resort Hotel bookings
📅 Arrival date and monthly booking analysis
💰 Analysis of booking and required car parking charges
❌ Cancellation and repeated guest analysis
⏳ Waiting-list duration analysis
🌍 Country-wise booking analysis
🍽️ Meal and reserved room-type analysis
👥 Guest and adult distribution analysis
📈 Analysis of weekend nights, week nights, and special requests
🔎 Interactive filters and slicers for dynamic exploration
